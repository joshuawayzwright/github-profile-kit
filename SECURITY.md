# Security policy

## Reporting a vulnerability

Please email **superadmin2712@gmail.com** with "Security" in the subject line. Include the steps to reproduce the problem and what you expected to happen. Please don't open a public issue for a security problem.

You'll get a reply within 7 days.

## Scope

This is a static, browser-only app. It has no server, no accounts and no analytics, and it doesn't send what you type anywhere. Reports about the code in this repository are in scope. Reports about GitHub Pages hosting itself should go to GitHub.
